# 设置页静态可见字符串覆盖（2026-10-30，Cursor 3.27.22 / 3.27.14）

## 为什么之前漏了

词典是按 box（Linux、免费套餐）上**实际渲染出来**的文案补的。`coverage-scan.mjs` 只统计渲染出来的 DOM。按功能开关、套餐、平台或管理员策略隐藏的分区从来没有渲染过，所以这些文案也就没进词典。漏掉的有：

- 远程控制、保持唤醒、已配对的设备、自托管 Worker
- 各运行模式的说明文字和确认框
- Tab 的 Python 自动导入
- 隐私、用量和按需计费的分支

## 新口径：静态可见字符串

`node scripts/static-strings.mjs <安装根>`（依赖 acorn）用词法分析直接扫两个工作台 bundle：

- **扫描范围**：
  - glass 按模块名过滤出设置相关模块。
  - desktop 的设置代码没有模块名，改为取设置组件命名空间（Root/Entry/Preview）前后 1500 个 token。
- **收录**：展示上下文里的字面量和模板，即 `label` / `description` / `title` / `children` / 三元表达式等。
- **排除**：日志、`Error(...)` 和标识符。
- **判定**：每条都对照词典、模板词典、DOM 规则、锚点片段和保留清单判断是否已覆盖。
- **有意保留英文**：
  - `scripts/coverage-keep.json`：品牌和术语。
  - `scripts/static-skip.json`：仅内部构建可见的开发项、日志、套餐名片段。
