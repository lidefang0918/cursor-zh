目标：精准、稳定、速度快、易于使用。全部改动只在 box 上做和测，没动你 Mac 上的 Cursor，也没 push。

## 按目标分的改动

### 精准
- **新的 NLS 专用词典 `dicts/zh-cn.nls.json`（1181 条）**：
  - 覆盖 Cursor 自己加、微软语言包里没有的菜单、命令、对话框、设置说明、受限模式提示等。
  - 只按下标写进 nls.messages.json，不参与 bundle 静态替换和 DOM 补漏，所以 “Rich” 这类泛词不会误伤代码或用户内容。
  - 测试检查占位符 `{0}`、助记符 `&&`、换行、`](command:)` 链接和术语表是否一致。
- **命令面板**：DOM 运行时现在能处理整段“分类: 标题”文本，只翻标题，英文别名照常保留，方便搜索。另外补了删除旧对话、隐藏聊天、在终端中生成、升级套餐等词条。
- **之前已完成**：
  - 补了“自定义”页和剩余开发者命令的词条。
  - 加了术语一致性检查（智能体、撤销、插件市场等），纳入 npm test。
  - 回归测试保证聊天消息、Markdown、编辑器、输入框、代码、文件名永远不翻。
- **覆盖率扫描**：
  - 默认改为严格口径；命令面板滚到底，取全部命令。
  - 新增扫描范围：经典窗口的标题栏、侧边栏、面板、状态栏，编辑器右键菜单，以及智能体窗口主界面。

### 稳定
- 写文件改为原子替换：先写临时文件并校验，再 rename 覆盖；中途失败会全部回滚。有崩溃安全测试。
- 重复汉化是幂等的：按“词典 + 运行时 + 锚点”的指纹判断，内容有更新就从原版备份重新打补丁，不用先还原。
- DOM 运行时：单个节点出错会被隔离，错误太多时自动停用；有随机树模糊测试。
- 错误码附中文“下一步”建议。
- 新版本适配只需一条命令 `scripts/new-version.sh`，另有 CI 草稿。
- 本轮跨平台离线核对全部通过，“未命中 0、JS 语法检查通过、checksum 正确”：
  - 3.27.22：Linux deb、Windows 用户版和系统版、mac arm64 和 x64
  - 3.27.14：mac、Windows

### 速度快
- 模板片段替换的两次优化：
  - 昨晚：改成一次定位、一次拼接，8.3s → 1.9s（只算静态部分）。
  - 今晚：改成单个正则一遍扫完（命中数和锚点对不上时退回逐条查找），整套补丁 2.6s → 2.2s。
- DOM 运行时：按批缓存祖先判定，类名用正则匹配。实测开销在 1.7%～4.9%，不再继续优化。

### 易于使用
- 桌面版：一个大按钮加进度条。检测到汉化失效或有更新时，提示一键重新汉化；失败时显示下一步怎么做。
- 三个平台统一了应用图标。
- 新增给普通用户看的中文说明 `docs/使用说明.md`。
- 新增 Windows 命令行包（<1MB），借用 Cursor 自带的 Node 运行。
