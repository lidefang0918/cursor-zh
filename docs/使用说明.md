# Cursor 一键汉化 · 使用说明

把 Cursor 的界面（菜单、设置、命令面板、智能体窗口……）换成简体中文。随时可以一键还原成英文原版。

> 本工具与 Cursor 官方无关。它会修改 Cursor 的安装文件，修改前自动备份，还原后与原版逐字节相同。
> 不会读取或修改你的登录信息、聊天记录和项目文件。

## 支持的版本

| 系统 | Cursor 版本 | 状态 |
|---|---|---|
| Linux（deb / rpm 安装，或 AppImage） | 3.27.22 | 已在测试机上完整验证 |
| Windows 10/11 x64（用户版 / 系统版安装） | 3.27.14、3.27.22 | 已离线验证，等待真机反馈 |
| macOS（Apple 芯片 / Intel） | 3.27.14、3.27.22 | 已离线验证，等待真机反馈 |

查看版本：Cursor 菜单 **Help → About**（帮助 → 关于）。版本不在上表里时，工具会提示“暂未适配”，不会改动任何文件。

## 下载哪个文件

工具有两套界面：**新版（文件名带 `tauri`，几 MB，推荐）** 和 **旧版（Electron，约 80 MB，作为备用）**。两者按钮、汉化结果完全一样，装一个即可（Linux 上不要两个 deb 同时装）。

| 系统 | 文件 | 说明 |
|---|---|---|
| Windows | `…-tauri-win-x64-setup.exe`（约 4 MB） | **推荐**。安装后在开始菜单 / 桌面找到“Cursor 一键汉化” |
| Windows | `…-tauri-win-x64-portable.exe`（约 4.5 MB） | 免安装，双击即用 |
| macOS | `…-tauri-mac-universal.dmg` | 由 GitHub Actions 在 Mac 上构建（见下文“macOS 版怎么来的”）。拖到“应用程序”，**首次打开请右键 → 打开** |
| Linux | `…-tauri-amd64.deb`（约 3 MB）/ `…-tauri-x86_64.AppImage` | deb：`sudo apt install ./文件名.deb`，命令行 `cursor-zh`；AppImage 自带图形库所以较大，加执行权限后双击 |
| 备用 | `…-win-x64-setup.exe` / `…-win-x64-portable.exe` / `…-mac-arm64.zip` / `…-mac-x64.zip` / `…-amd64.deb` / `…-x86_64.AppImage`（不带 tauri） | 旧版 Electron 界面，新版打不开时用 |
| Windows | `…-win-x64-cli.zip` | 不想装图形界面时用：解压后双击“一键汉化.bat” |

下载后可以用 `SHA256SUMS.txt` 核对文件是否完整。

### 新版为什么这么小

- 界面用系统自带的网页组件：Windows 是 WebView2（没有时安装包会自动下载），macOS 是 WKWebView，Linux 是 WebKitGTK。
- 不自带 Node：汉化引擎由**你已安装的 Cursor 主程序**以 `ELECTRON_RUN_AS_NODE=1` 方式运行（后台进程、不弹窗口、跑完即退）。Cursor 主程序文件本身不会被改动。
  - macOS：汉化时要给 Cursor 重新签名，会改写 `Cursor.app/Contents/MacOS/Cursor`。为了不“边跑边改”自己，工具先把 Cursor.app 用 APFS 克隆（瞬间完成、几乎不占空间）到临时目录，用克隆里的程序跑引擎，结束后自动删除。
  - 找不到 Cursor 时依次尝试：环境变量 `CZL_NODE` 指定的 node、系统里 18 以上版本的 node；都没有就提示，并提供“手动选择 Cursor 安装位置…”按钮。
- 引擎和词典打包在程序里，首次运行解压到用户缓存目录（Windows `%LOCALAPPDATA%\local.cursor-zh-localizer.tauri\engine`，Linux `~/.cache/local.cursor-zh-localizer.tauri/engine`，macOS `~/Library/Caches/local.cursor-zh-localizer.tauri/engine`），可随时删除。

自检（不开窗口、不改文件）：`cursor-zh --self-test 输出.json`（Windows 是 `cursor-zh.exe`），会写出检测到的 Cursor 安装、版本和引擎运行环境。

### macOS 版怎么来的

macOS 版必须在 Mac 上编译。仓库里有 `.github/workflows/tauri.yml`：推到 GitHub 后在 Actions 里手动运行（或打 `tauri-v*` 标签），`macos-latest` 会构建 Apple 芯片 + Intel 通用版（universal）的 `.app` 和 `.dmg`，同时也会构建 Windows / Linux 版并附上 SHA256SUMS，在运行页面的 Artifacts 里下载。

自己在 Mac 上构建：

```
xcode-select --install                     # 首次
curl https://sh.rustup.rs -sSf | sh        # 安装 Rust
rustup target add aarch64-apple-darwin x86_64-apple-darwin
npm ci && npm test
cd apps/tauri && npx tauri build --target universal-apple-darwin --bundles app,dmg
# 产物：apps/tauri/src-tauri/target/universal-apple-darwin/release/bundle/{macos,dmg}/
```

构建只用临时签名（ad-hoc），没有 Apple 公证，所以首次打开要右键 → 打开。构建过程不会碰本机的 Cursor。

## 三步用法

1. 打开“Cursor 一键汉化”，窗口顶部会显示找到的 Cursor 位置和版本。
2. 点大按钮 **一键汉化**。如果 Cursor 正开着，会先问你是否关闭它（未保存的内容 Cursor 会自动保留），完成后自动重新打开。
3. 看到 **✔ 汉化完成** 就好了。个别地方如果还是英文，再重启一次 Cursor。

想换回英文：点 **一键还原**。

## 按钮上的字是什么意思

| 按钮 / 提示 | 含义 | 该做什么 |
|---|---|---|
| 一键汉化 | 还没汉化 | 点它 |
| 已汉化 ✔（灰色） | 已经是最新汉化 | 不用做什么 |
| 更新汉化 | 本工具有新版本，带了更多/更准的译文 | 点它，几秒钟完成，语言包和设置不动 |
| 重新汉化 / “Cursor 已更新，汉化已失效” | Cursor 自动更新后英文回来了 | 点它重新汉化 |
| “Cursor 已更新到 X，暂未适配” | 新版本本工具还没跟上 | 等工具更新；期间 Cursor 照常可用（英文） |

重复点“一键汉化”是安全的：已经是最新时会直接提示“已是最新汉化，无需重复操作”，不会再改文件。

## 需要管理员权限的时候

只有“把文件写进安装目录”这一步可能需要权限，工具本身始终以普通用户运行：

- **Windows 系统版**（装在 `C:\Program Files`）：会弹出“用户账户控制”，点 **是**。点了“否”也没关系，窗口会给出一条命令，在“终端(管理员)”里粘贴执行后，再点一次按钮即可。
- **Linux deb/rpm**：会弹出系统授权窗口，输入你的登录密码。
- **macOS**：如果提示被“App 管理”拦截，到 **系统设置 → 隐私与安全性 → App 管理**，给“Cursor 一键汉化”打开开关，再点一次按钮。

## macOS 特别说明

- 请先把 Cursor 放在“应用程序”文件夹里（直接在“下载”里打开的 Cursor 是只读的）。
- 汉化后首次启动可能弹出“Cursor Safe Storage”钥匙串提示，选 **始终允许**。
- **更新 Cursor 前先点“一键还原”**，更新完再汉化，否则 Cursor 自带的更新可能失败。

## 出错了怎么办

失败时窗口会用中文写明原因，并给出 **下一步** 建议，照做即可。还不行的话：

1. 点 **打开日志**，把日志文件（`gui.log`；旧版是 `desktop.log`，命令行版是 `cli.log`）发给我们；
2. 附上窗口截图和 Cursor 的版本号（Help → About）。

日志、备份和状态文件的位置：

| 系统 | 位置 |
|---|---|
| Windows | `%APPDATA%\cursor-zh-localizer` |
| macOS | `~/Library/Application Support/cursor-zh-localizer` |
| Linux | `~/.config/cursor-zh-localizer` |

`backups\<版本号>` 里是汉化前的原版文件，“一键还原”就靠它，请不要删除。

## 卸载

先在工具里点 **一键还原**，再卸载本工具（Windows：设置 → 应用；macOS：把 App 拖进废纸篓；Linux：`sudo apt remove cursor-zh`，旧版是 `sudo apt remove cursor-zh-localizer`）。只卸载工具不会还原 Cursor。
