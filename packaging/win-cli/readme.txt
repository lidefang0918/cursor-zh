Cursor 一键汉化 · Windows 命令行版 0.1.0（测试版）
================================================

【支持的版本】
Cursor 3.27.14、3.27.22（Windows x64）。
在 Cursor 里点 Help → About（帮助 → 关于）查看 Version。
其他版本会显示“暂未适配”，不会改动任何文件。
用户版安装（%LOCALAPPDATA%\Programs\cursor）和系统版安装（C:\Program Files\cursor）都支持。

【使用前】
1. 把整个 zip 解压到任意文件夹（比如桌面）。不要在压缩包里直接双击运行。
2. 建议先完全退出 Cursor。没退出也可以，工具会先正常关闭 Cursor（未保存的内容由 Cursor 自动保留），完成后重新打开。
3. 本工具直接借用 Cursor 自带的运行环境，不需要另外安装 Node。

【一键汉化】
双击“一键汉化.bat”，会先显示当前状态，然后开始汉化，完成后自动打开 Cursor。
- 双击 .bat 可能出现蓝色窗口“Windows 已保护你的电脑”，或者“是否运行此文件”的安全警告。
  这是因为文件是从网上下载的。点“更多信息”→“仍要运行”，或者点“运行”即可。
  也可以事先对 zip 点右键 → 属性 → 勾选“解除锁定”，再解压。
- 如果 Cursor 装在 Program Files（系统版），会弹出“用户账户控制”窗口（程序是 Windows PowerShell），点“是”。
  如果点了“否”，窗口里会给出一条命令：右键开始菜单 →“终端(管理员)”，粘贴并执行这条命令，然后再双击“一键汉化.bat”。
- 第一次汉化后，如果界面仍有英文，请再重启一次 Cursor（语言包要重启后才会生效）。

【一键还原】
双击“一键还原.bat”。会把 Cursor 恢复成汉化前的原版文件（逐字节相同），并卸载中文语言包，恢复原来的界面语言。
Cursor 自动更新后，汉化会失效，界面会变回英文。只要新版本已适配，再双击“一键汉化.bat”即可。
拿到新版本的本工具后，也双击一次“一键汉化.bat”：会显示“汉化已更新”；已经是最新时显示“已是最新汉化，无需重复操作”，不会改动文件。

【查看状态】
双击“查看状态.bat”，可以看到检测到的 Cursor 安装位置、版本，以及是否已适配、是否已汉化。

【日志和备份】
都在 %APPDATA%\cursor-zh-localizer（在资源管理器地址栏输入这个路径并回车即可打开）：
  cli.log            每次运行的完整输出。出问题时请发这个文件
  backups\<版本号>\   汉化前原始文件的备份，还原就靠它
  state.json         当前汉化状态

【测完请截图发回】
1. 三个 .bat 运行后的黑色窗口：最后几行和 “✔/✖” 结果都要能看到。
2. 如果出现安全警告或 UAC 窗口，各截一张。
3. 汉化后的 Cursor：
   - 主窗口
   - 顶部菜单“文件/编辑/查看”展开
   - 设置页（Ctrl+,）
   - 智能体窗口（Agents）及其菜单
   - 命令面板（Ctrl+Shift+P）
4. 还原后的 Cursor 主窗口（应该是英文）。
5. Help → About 版本信息。
6. 再附上 %APPDATA%\cursor-zh-localizer\cli.log 文件。
